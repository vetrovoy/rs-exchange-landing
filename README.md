# Monkey Exchange

Статический сайт на HTML и CSS без сборки. Небольшой JavaScript закрывает меню при выборе пункта и отправляет события в Яндекс Метрику.

Подключен счетчик Яндекс Метрики `112456455` с настройками из предоставленного кода. Все три кнопки «Обменять валюту» отправляют событие `exchange_click` перед переходом в Telegram; ожидание ограничено 500 мс. В интерфейсе Метрики необходимо создать цель типа «Целевое событие» с идентификатором `exchange_click`, затем выбрать ее в Яндекс Директе. Это цель клика по кнопке, а не подтвержденной заявки в боте. Настройки рекламной кампании выполняются отдельно.

Откройте `index.html` в браузере. Три раздела — `#home`, `#delivery`, `#online` — размещены последовательно в одном документе. Адреса `steps.html` и `exchange.html` перенаправляют на соответствующие якоря.

Одна классическая страница с общей вертикальной прокруткой и единственной шапкой. Разделы имеют естественную высоту, кнопки Telegram расположены после их содержимого. Меню ведет к якорям разделов. Внутренних областей прокрутки и автоматического притягивания нет. Мобильный контейнер ограничен 430 px и расположен по центру.

Все три кнопки «Обменять валюту» ведут на https://t.me/monkey_obmen_vietnambot?start=id20. Закрепленная шапка содержит меню якорей и ссылку «Мой инстаграм»: https://www.instagram.com/vlog_23rus.

Изображения и шрифты находятся в `assets/`. Новый коллаж Вовы — `assets/home/vova-currency-collage.png`. В разделах доставки и онлайн-обмена иллюстрации оставлены только у третьих шагов. Неиспользуемые ресурсы удалены.

Проверки: Chromium, ширины 320, 375, 390, 430, 768, 1440 px, короткий экран 390×400 и альбомная ориентация 844×390. Проверены положение кнопок, прокрутка до конца, отсутствие горизонтального переполнения, якоря и перенаправления. WebKit установить не удалось из-за тайм-аутов загрузки; проверка в Safari на устройстве остается необходимой.

Публикация: https://vetrovoy.github.io/rs-exchange-landing/ — GitHub Pages из корня ветки `master`.

Основной адрес: https://vietnamlive.ru/exchange/ (сервер `5.42.99.175`). Адрес `/exchange` перенаправляется на `/exchange/`, чтобы относительные ссылки на ресурсы работали корректно.

Рекламные адреса: `/ex/`, `/ch/`, `/rub/`, `/vnd/` на том же домене показывают те же файлы, сохраняя выбранный путь в адресной строке. Адреса без завершающего слеша перенаправляются на вариант со слешем с сохранением строки запроса (UTM, `yclid`). Все адреса используют счетчик `112456455`, событие `exchange_click` и параметр запуска бота `start=id20`.

На сервере исходники находятся в `/opt/rs-exchange`. Публичные HTML, CSS и `assets/` размещены в постоянном Docker-томе Caddy: `/var/lib/docker/volumes/vietnamlive_backend_caddy_data/_data/exchange`, внутри контейнера — `/data/exchange`. Файлы сохраняются при пересоздании контейнера. Маршрут `handle_path /exchange/*` добавлен в `/opt/rs-admin/Caddyfile`; резервная копия до публикации — `/opt/rs-admin/Caddyfile.before-exchange-20260910`. Остальные маршруты не изменены. Обновления GitHub Pages не обновляют этот сервер автоматически: после обновления исходников нужно скопировать публичные файлы в указанный каталог.
