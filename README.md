# Monkey Exchange

Статическая мобильная верстка на HTML и CSS, без JavaScript и сборки.

Откройте `index.html` в браузере. Меню связывает главную страницу, доставку (`steps.html`) и обмен онлайн (`exchange.html`). Все изображения и шрифты находятся в `assets/`, подключение к интернету не требуется.

Контейнер занимает доступную ширину экрана до 430 px; на планшете и компьютере остается по центру. Текст и блоки расположены в обычном потоке документа. Каждый шаг содержит отдельную иллюстрацию, которая отображается целиком. Шрифты и отступы не уменьшаются пропорционально всей странице.

Кнопка «Получить донги» ведет на страницу доставки. Кнопка «Оформить онлайн» отключена: обработка заявок не входит в статическую верстку.

Основа дизайна: Figma `ug89vCQLs3nDumbCHNPkN7`, узлы `1:279`, `1:311`, `1:343`. На главной используется коллаж `assets/home/founder-currency-collage.png` и отдельные декоративные подписи. На остальных страницах иллюстрации размещены под текстом соответствующего шага. Inter загружен из Google Fonts.

Изображения названы по содержимому и сгруппированы по страницам: `assets/home`, `assets/steps`, `assets/exchange`. Общие иконки и шрифты находятся в `assets/`. Неиспользуемые изображения и временные файлы удалены. Файл `home.css` содержит стили только главной страницы.

Проверено в Chromium на ширинах 320, 375, 390, 430, 768 и 1440 px: локальные ресурсы, отсутствие горизонтальной прокрутки, ограничение ширины, меню с клавиатуры и переходы. Проверено прямое открытие HTML с диска.
